Executive Strategy Briefing
Ringkasan Eksekutif & Pertimbangan Strategis

1. Klarifikasi Modal $160: Angka $160 adalah biaya tetap server (Fixed Infra) selama 1 tahun ($13,33/bulan untuk VPS 8GB RAM, PostgreSQL Docker, Caddy, Cloudflare R2, dan domain), bukan biaya token AI. Biaya token AI bisa $0 bagi kita karena menggunakan BYOK (user membayar token ke API provider mereka sendiri). Jika tanpa BYOK, 75 user akan memakan biaya API $5.400–$18.000/tahun (boncos besar).

2. Riset Fee AppSumo Resmi: Model Marketplace mengenakan komisi 30% (Vendor membawa pulang 70% bersih). Ditambah cadangan refund wajar 12%, realisasi kas bersih kita adalah $6.018,60 dari penjualan kotor $9.925.

3. Strategi "BYOK Unlimited": Diberikan HANYA di Tier 4 ($249) dan Tier 5 ($399). Karena user memakai kunci API mereka sendiri, jumlah query berapapun biaya API-nya $0 bagi kas platform.

4. Jaminan Profit 5 Tahun (Zero New Users): Dari kas bersih $6.018, total beban operasional 5 tahun penuh (server + subsidi T1-T2 + support) hanya $2.875. Di akhir tahun ke-5, kita masih mengantongi sisa laba bersih +$3.143,90 (Net Margin 52,2%) tanpa butuh 1 user baru pun!

3 Aturan Emas Mitigasi Risiko untuk Eksekusi
  1. Edukasi Transparan di Listing AppSumo: Cantumkan jelas bahwa "Unlimited Tracking berjalan di atas API Key OpenRouter/OpenAI pribadi Anda dengan tarif grosir langsung (sekitar $0,0005 per query)" untuk mencegah kesalahpahaman.
  2. Rate-Limiting Concurrency (Anti Server Overload): Batasi task paralel konkuren (T4 = 3 worker bersamaan, T5 = 10 worker bersamaan) agar server VPS 8GB RAM tidak mengalami antrean macet.
  3. Pembersihan Data Mentah (Auto-Prune 60 Hari): Respons teks mentah LLM disimpan 60 hari untuk riwayat; setelahnya otomatis diringkas menjadi angka agregat skor peringkat dan sentimen permanen.

REKOMENDASI FINAL KEPUTUSAN:

Struktur ini siap dieksekusi. Modal awal $160 menutup seluruh biaya server tahun pertama, skema 5-tier menghasilkan kas bersih ~$6.000 di awal, dan jaminan laba 5 tahun sebesar ~$3.140 memberikan bantalan keuangan yang sangat aman bagi perusahaan.
