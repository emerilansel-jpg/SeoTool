## Supastarter Theme Adoption: Palette + Layout Polish

### Goal

Mengadopsi visual identity Supastarter (blue indigo #4e6df5, warm background #fafafe, near-black dark #070d12) ke SeoTool.im **tanpa mengganti DaisyUI** — cukup swap token values + polish layout.

---

### 1. Theme Token Swap — `src/client/styles/app.css`

Meng-update kedua DaisyUI themes (`openseo` + `openseo-dark`) untuk match Supastarter palette:

**Light (`openseo`):**

- `base-100`: `oklch(100% 0 0)` → `#fafafe` (warm white, bukan pure white)
- `base-200`: `oklch(97% 0 0)` → `#f8fafc` (slate-50)
- `base-300`: → `#e3ebf6` (Supastarter border blue-tinted)
- `primary`: `oklch(50% 0.12 262)` → `#4e6df5` (Supastarter indigo-blue)
- `secondary`: green → `#292b35` (dark slate, Supastarter's secondary)
- `neutral`: → `#292b35`
- `base-content`: → `#292b35`
- `info`: → `#4e6df5`
- `success`: → `#39a561` (Supastarter green)
- `warning`: → `#e5a158` (Supastarter highlight/amber)
- Radius box: `0.75rem` → `0.75rem` (same, but ensure cards use `rounded-2xl`)

**Dark (`openseo-dark`):**

- `base-100`: `oklch(18% 0 0)` → `#0d1116` (Supastarter dark card)
- `base-200`: → `#070d12` (Supastarter dark background, near-black blue)
- `base-300`: → `#2b303d` (Supastarter dark border)
- `primary`: → `#5581f7` (Supastarter dark primary)
- `base-content`: → `#e9eef3`
- `secondary`: → `#e9eef3`
- `neutral`: → `#e9eef3`
- `success`: → `#39a561`
- `warning`: → `#e5a158`

### 2. Radial Glow Background — `AppShell.tsx`

Tambahkan subtle radial gradient di main content area (polish Supastarter-style):

```tsx
<div className="... relative">
  <div
    className="pointer-events-none absolute inset-0 opacity-[0.03]"
    style={{
      background:
        "radial-gradient(ellipse 80% 50% at 50% -20%, var(--color-primary), transparent)",
    }}
  />
  {children}
</div>
```

### 3. Card Radius Polish

Pastikan card-class menggunakan `rounded-2xl` (Supastarter signature) dengan menambahkan override di app.css:

```css
.card {
  border-radius: var(--radius-box);
}
```

Dan update key card containers di layout untuk konsistensi visual.

### 4. Auth Page Polish — `AuthPage.tsx`

- Background: tambahkan subtle primary glow di belakang auth card (Supastarter AuthWrapper pattern).
- Card: `rounded-2xl` + border yang lebih soft.

### 5. Quality Gates

- tsc, tests (no functional change — pure visual), prettier.

**Yang TIDAK diubah:** Semua DaisyUI component classes (`btn`, `card`, `input`, `tabs`, `modal`, dll), sidebar structure, navigation logic, routing. Hanya color values + subtle visual polish.
