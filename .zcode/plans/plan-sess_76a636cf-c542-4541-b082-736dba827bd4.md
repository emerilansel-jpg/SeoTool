## PayPal Implementation Plan for seotool.im

### Context
Replace the entire Autumn/Stripe billing integration with PayPal Subscriptions (Billing Plans). The quota enforcement layer (`QuotaService`, `QuotaRepository`, `quota-gate`) and plan definitions (`plans.ts`) remain unchanged — only the payment provider layer is replaced.

**Scope:** ~40 files touched. 1 package removed (`autumn-js`), PayPal REST API used directly (no npm package needed, native fetch works on Cloudflare Workers).

---

### Phase 1: PayPal REST Client + Environment Config
1. **New file: `src/server/billing/paypal.ts`** — Lazy-loaded PayPal REST API client with OAuth2 token caching (8h TTL), methods: `getAccessToken()`, `request()`, facade for `paypal.subscriptions`, `paypal.products`, `paypal.billingPlans`, `paypal.billingPortal`
2. **Update `src/env.d.ts`** — Add `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET`, `PAYPAL_MODE`, `PAYPAL_WEBHOOK_ID`
3. **Update `.env.hosted.example`, `.env.production.example`, `alchemy.run.ts`** — Replace `AUTUMN_*` env vars with `PAYPAL_*`
4. **Update `package.json`** — Remove `autumn-js` dependency

### Phase 2: Shared Constants + Plan ID Mapping
1. **Update `src/shared/billing.ts`** — Rename `AUTUMN_*` constants to `PAYPAL_*` (e.g., `PAYPAL_CREDITS_FEATURE_ID`), rename `autumnSeoDataCreditsToUsd` → `creditsToUsd`
2. **Update `src/shared/plans.ts`** — Rename `AUTUMN_PLAN_IDS` → `PAYPAL_PLAN_IDS` (values become PayPal Billing Plan IDs), rename `planTierFromAutumnPlanId` → `planTierFromPaypalPlanId`
3. **Update ~15 import sites** across server and client files

### Phase 3: Database Schema Migration
1. **Update `src/db/quota.schema.ts` + `src/db/pg/quota.schema.ts`** — Rename `autumnSubscriptionId` → `paypalSubscriptionId`
2. **Create migrations** — `drizzle/0047_rename_autumn_to_paypal.sql` and `drizzle-pg/0020_rename_autumn_to_paypal.sql`
3. **Update `QuotaRepository.ts`** — Rename field in `upsertSubscription()` input type

### Phase 4: Credits System (Replace Autumn Balance Tracking)
PayPal has no native credits/balance — we implement it using the existing `usage_quota` table.
1. **New file: `src/server/billing/credits.ts`** — `grantMonthlyCredits()`, `getCreditBalance()`, `deductCredits()`, `topupCredits()`
2. **Rewrite `src/server/billing/subscription.ts`** — Replace all `autumn.check()`/`autumn.track()` calls with local credits service; remove `autumn.customers.getOrCreate()` calls
3. **Update `src/serverFunctions/billing.ts`** — Replace `autumn.billing.openCustomerPortal()` with PayPal portal API; replace `fetchAutumnEventsPage()` with local DB queries

### Phase 5: PayPal Checkout Flow
1. **New file: `src/serverFunctions/paypal-checkout.ts`** — `createPaypalSubscription(tier)` (creates PayPal subscription, returns approve URL), `capturePaypalSubscription(subscriptionId)`
2. **Update `src/routes/_authenticated.subscribe.tsx`** — Replace `useCustomer` + `customerQuery.attach()` with PayPal redirect flow
3. **Update `src/client/features/onboarding/OnboardingChatConversation.tsx`** — Same checkout replacement
4. **Update `src/routes/__root.tsx`** — Remove `<AutumnProvider>` wrapper
5. **Delete `src/routes/api/autumn/$.ts`** — No longer needed

### Phase 6: PayPal Webhook Handler
1. **New file: `src/server/billing/paypal-webhook-verify.ts`** — PayPal webhook signature verification (use `/v1/notifications/verify-webhook-signature` API)
2. **New file: `src/server/billing/paypal-webhook.ts`** — Handle `BILLING.SUBSCRIPTION.CREATED/UPDATED/CANCELLED/EXPIRED` events → `syncPaypalCustomerStatus()`
3. **Update `src/server.ts`** — Route `/api/paypal/webhook` instead of `/api/autumn/webhook`

### Phase 7: Customer Status Sync + Model
1. **Update `src/server/billing/customer-status-model.ts`** — Accept PayPal subscription objects, use `PAYPAL_PLAN_IDS`, rename `autumnSubscriptionId` → `paypalSubscriptionId`
2. **Update `src/server/billing/customer-status-sync.ts`** — `syncAutumnCustomerStatus()` → `syncPaypalCustomerStatus()`, use PayPal API instead of Autumn
3. **Update `src/server/billing/loops-sync.ts`** — Update comments

### Phase 8: Client-Side Components
1. **Remove all `useCustomer`/`useAggregateEvents` imports from `autumn-js/react`** in 8 files
2. **New file: `src/client/features/billing/use-billing.ts`** — Local hooks: `usePlanTier()`, `useCreditBalance()`, `useBillingStatus()` that fetch from local DB
3. **Update billing page, status banners, free plan banner, hosted plan gate, usage chart** — Replace Autumn hooks with local hooks
4. **Update `src/routes/_app/billing.tsx`** — Replace Stripe portal with PayPal portal redirect

### Phase 9: Cleanup + Tests
1. **Delete:** `autumn.ts`, `autumn-webhook.ts`, `svix.ts`, `svix.test.ts`, `api/autumn/$.ts`
2. **Update tests:** `customer-status-model.test.ts`, `subscription.test.ts`, `QuotaService.test.ts`
3. **Update build config:** `vite-plugin-lean-worker-bundle.ts`, `.github/workflows/ci.yml`
4. **Replace docs:** `docs/AUTUMN_PLANS.md` → `docs/PAYPAL_BILLING.md`
5. **Update greptile config:** `.greptile/config.json`, `.greptile/files.json`, `.greptile/rules.md`
