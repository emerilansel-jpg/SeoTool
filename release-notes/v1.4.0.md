# Unified BYOK Architecture & Editorial Overhaul

**Released: October 2026**

## What's new

- **Unified Settings BYOK**: Store DataForSEO and custom AI provider (OpenAI, PesatRouter, Claude) API keys once in **Settings > BYOK Integrations**. All analysis tools automatically utilize saved credentials with zero inline key inputs.
- **Local Map Rank (GMB Geo-Grid) SAB Support**: Enhanced pinpoint centroid tracking for Service Area Businesses (SAB) without physical storefronts. Added custom scan radius up to 30 miles and matrix density up to 15x15 (225 pins) with live SOLV score calculation.
- **Editorial Blog Redesign**: Introduced left-rail sticky Table of Contents with mobile toggle, expanded reading canvas up to 1440px container, and unified brand styling for newsletter and site audit CTAs.

## Improvements

- Streamlined database connection pooling for high-density background Geo-Grid workers.
- Instant cache revalidation for blog articles and server-side reading time calculations.
